# Population Balance Portal

An open educational portal dedicated to **Population Balance Modelling**, with teaching materials, computational examples and references for students and researchers.

## Planned contents

* Introduction to population balance equations
* Number density functions and internal coordinates
* Solution methods
* Method of moments
* Quadrature-based moment methods
* Monte Carlo methods
* Crystallization
* Aerosols and particulate systems
* Multiphase-flow applications
* Exercises and computational examples
* Python and MATLAB code
* Recommended literature

## Website

The teaching portal will be available at:

https://population-balance-portal.github.io
